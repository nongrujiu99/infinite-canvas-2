# Canvas Node Guide

## Common operations

- Create nodes from the canvas toolbar or drop image, video, MP3, and WAV files onto the canvas.
- Click to select a node; use `Shift / Cmd` with click to add or remove it from a multi-selection.
- Drag nodes to move them and use corner handles to resize them.
- Connect the handles on either side of a node; generation nodes read valid upstream content.
- Use the top toolbar or context menu for copy, delete, download, edit, and type-specific actions.

## Text nodes

- Double-click the body or use **Edit text** to edit content.
- Generate into an empty node or create a connected rewrite to the right of a populated node.
- Use `@` to reference connected text, image, video, and audio resources; image references appear as thumbnails.
- Use **Generate image** to create and connect a generation node from the current text.

## Image nodes

- Upload or drop images, insert them from My Assets, save them as assets, or download them.
- Direct generation reuses an empty image node and keeps batch results as switchable slots. A generation-config node instead creates or reuses downstream image nodes for its configured count.
- Use a populated image as a reference for another generation.
- Crop, split, mask, upscale, angle, and reverse-prompt actions create the required operation or result nodes.

## Video nodes

- Upload or drop video files and play them with the native player.
- Generate into an empty node and use connected text, images, video, or audio as supported inputs.
- Saved asynchronous task IDs allow polling to continue after a refresh or through **Get task status**.
- Capture the first, last, or current frame from the context menu to create a connected image node.

## Audio nodes

- Upload MP3 or WAV files and play them in the node.
- Generate into an empty node with a prompt and a configured audio model.
- Connect audio to generation workflows that accept audio references.

## Generation nodes

- Switch among text, image, video, and audio generation modes.
- Read valid upstream resources and configure the model and parameters for the active mode.
- Reference connected resources with `@` and reuse the current node settings for later runs.

## Group nodes

- Select at least two nodes and choose **Group**, or press `Ctrl / Cmd` + `G`.
- Select a group and choose **Ungroup**, or press `Ctrl / Cmd` + `Shift` + `G`.
- Drag nodes into or out of a group. Connecting a group exposes its populated child resources as input.

## Image-operation nodes

- Create operation nodes from image or video actions, or from the compatible connection menu.
- Each operation accepts only compatible source types and writes or connects its result to a resource node.
