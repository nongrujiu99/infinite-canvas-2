# 画布节点操作手册

## 通用操作

- 从画布工具栏新建节点，或把图片、视频、MP3、WAV 文件拖入画布。
- 点击节点进行选择；按住 `Shift / Cmd` 点击可追加或取消选择。
- 拖动节点移动位置，拖动四角控制点调整尺寸。
- 使用节点两侧连接点建立上下游关系，生成节点会读取有效的上游内容。
- 顶部工具条和右键菜单提供复制、删除、下载、编辑及对应类型的操作。

## 文本节点

- 双击正文或使用顶部“编辑文字”进入文本编辑。
- 空文本节点可在下方输入框中生成文字，已有正文的节点可生成连接到右侧的改写结果。
- 输入框支持 `@` 引用已连接的文本、图片、视频和音频；图片引用会显示缩略图。
- 顶部“生图”会创建并连接一个生成配置节点，再使用当前文本开始图片生成。

## 图片节点

- 可上传、拖入或从“我的素材”插入图片，也可把图片保存到素材库或下载到本地。
- 空图片节点直接生成时会复用当前节点，批量结果保存在同一节点的多个结果槽位中；生成配置节点则按数量创建或复用下游图片节点。
- 有内容的图片节点可以作为参考图继续生成。
- 裁剪、切分、遮罩、放大、多角度和反推提示词等入口会创建对应的处理节点或结果节点。

## 视频节点

- 可上传或拖入视频，节点内使用原生播放器播放。
- 空视频节点可直接生成；文本、图片、视频和音频连接可作为视频生成输入。
- 异步任务 ID 会保存在节点中，刷新后可继续查询，也可手动获取任务状态。
- 有内容的视频可从右键菜单截取首帧、尾帧或当前帧，并生成连接的图片节点。

## 音频节点

- 可上传 MP3 或 WAV 文件并在节点内播放。
- 空音频节点可使用提示词和已配置的音频模型生成内容。
- 音频节点可以连接到支持音频参考的生成流程。

## 生成配置节点

- 可在文本、图片、视频和音频四种生成模式之间切换。
- 节点读取上游有效资源，并允许调整当前模式的模型和生成参数。
- 输入区支持 `@` 引用已连接资源；连续生成会复用当前节点配置。

## 分组节点

- 选择至少两个节点后点击“打组”，或按 `Ctrl / Cmd` + `G` 创建分组。
- 选择分组后使用“解散组”，或按 `Ctrl / Cmd` + `Shift` + `G` 取消分组。
- 节点可拖入或拖出分组；把分组连接到生成节点时，组内有效内容会作为输入。

## 图片处理节点

- 处理节点由图片或视频操作创建，也可从连接创建菜单选择支持的处理方式。
- 处理节点只接受与当前操作兼容的输入，完成后把结果写入或连接到新的资源节点。
