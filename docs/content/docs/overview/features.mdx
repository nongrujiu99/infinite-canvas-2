# Features

## Canvas projects

- Create, rename, duplicate, delete, and batch-manage canvas projects.
- Export one or more projects as ZIP files and import projects with their media.
- Keep projects in browser storage and optionally synchronize canvas projects through WebDAV.

## Infinite canvas

- Pan, zoom, reset the view, and switch between selection and pan tools.
- Use dots, grid lines, or a blank background in light and dark themes.
- Box-select, multi-select, copy, paste, delete, group, undo, and redo.
- Connect nodes and inspect related highlights, the minimap, and the element list.
- Export the whole canvas or selected nodes with their resources.

## Built-in nodes

- Text nodes edit, generate, or rewrite text and provide prompts to downstream nodes.
- Image nodes upload, display, download, generate, and edit images; direct batch generation keeps switchable results in one node.
- Video nodes upload, play, and generate video while retaining asynchronous task state.
- Audio nodes upload, play, and generate audio.
- Generation nodes combine upstream text and media with text, image, video, or audio settings; image mode creates or reuses result nodes for the configured count.
- Group nodes organize content and expose populated child nodes as generation input.
- Image-operation nodes support crop, split, mask, upscale, angle, reverse-prompt, and video-frame workflows.

## AI generation

- Configure multiple OpenAI-compatible or Gemini-format channels and models for each capability.
- Request providers directly from the browser or enable the local proxy when browser cross-origin rules require it.
- Configure model lists, defaults, aspect ratios, dimensions, quality, counts, reasoning effort, and audio or video parameters.
- Use custom invocation scripts for provider-specific request formats.
- Retry failed results and resume polling saved asynchronous video tasks after a refresh.

## Prompts and assets

- Search, filter, inspect, and copy prompts, then insert them into the canvas or save them to My Assets.
- Manage seven built-in prompt sources or add standard JSON sources, with browser-side caching.
- Store reusable text, image, and video assets in the browser and insert them into a canvas.

See [Third-party Prompt Sources](/docs/overview/third-party-prompt-repositories) for the built-in source list.

## Configuration, storage, and sync

- Import or export channels, default models, generation preferences, prompt sources, and WebDAV settings.
- Store canvas projects, assets, generation history, and API credentials primarily in the browser.
- Use WebDAV only as optional canvas-project synchronization; the project does not provide cloud accounts or cloud asset storage.
- Treat exported configuration files as sensitive because they contain API keys and WebDAV credentials.

## Current limitations

- API credentials are stored in the browser and are appropriate only for personal or trusted environments.
- The canvas is desktop-oriented and does not yet provide complete mobile touch support.
- Production Docker static-resource paths still require broader deployment verification.
