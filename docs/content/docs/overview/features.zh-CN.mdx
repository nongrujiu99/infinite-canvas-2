# 功能介绍

## 画布项目

- 创建、重命名、复制、删除和批量管理多个画布项目。
- 以 ZIP 文件导出单个或多个项目，并从 ZIP 文件导入项目和关联媒体。
- 项目默认保存在浏览器本地，可选使用 WebDAV 同步画布项目。

## 无限画布

- 平移、缩放、重置视图，并在选择和移动工具之间切换。
- 使用点阵、网格线或空白背景，支持浅色和深色主题。
- 框选、多选、复制粘贴、删除、分组、撤销和重做。
- 连接上下游节点，查看关联高亮、小地图和左侧元素列表。
- 导出整个画布或从元素列表导出选中节点及其资源。

## 内置节点

- 文本节点：编辑文本，生成或改写文字，并作为下游提示词输入。
- 图片节点：上传、展示、下载、生成和编辑图片；直接批量生成时支持在同一节点切换多个结果。
- 视频节点：上传、播放和生成视频，并保存异步任务状态。
- 音频节点：上传、播放和生成音频。
- 生成配置节点：组合上游文本和媒体，配置文本、图片、视频或音频生成参数；图片模式会按数量创建或复用结果节点。
- 分组节点：组织多个节点，并把组内有效内容作为生成输入。
- 图片处理节点：执行裁剪、切分、遮罩、放大、多角度、反推提示词和视频截帧等操作。

## AI 生成

- 配置多个 OpenAI 兼容或 Gemini 格式渠道，并分别管理文本、图片、视频和音频模型。
- 从浏览器直连配置的接口；遇到跨域限制时可启用本地代理。
- 支持模型列表拉取、默认模型、比例、尺寸、质量、数量、推理强度及音视频参数。
- 支持自定义模型调用脚本，适配不同接口格式。
- 生成结果和必要参数保存在节点中，失败后可重试；异步视频任务可在刷新后继续查询。

## 提示词和素材

- 搜索、筛选、查看和复制提示词，并将提示词插入画布或保存到“我的素材”。
- 管理 7 个内置提示词来源，也可添加标准 JSON 自定义来源；来源数据缓存在浏览器中。
- “我的素材”支持文本、图片和视频，可搜索、筛选、编辑、删除、下载或插入画布。

内置提示词来源及其数据地址见[第三方提示词来源](/zh-CN/docs/overview/third-party-prompt-repositories)。

## 配置、存储和同步

- 导入或导出渠道、默认模型、生成偏好、提示词来源和 WebDAV 配置。
- 画布项目、素材、生成记录和 API Key 主要保存在浏览器本地。
- WebDAV 仅用于可选的画布项目同步，不代表项目提供账号系统或云端素材库。
- 配置文件包含 API Key 和 WebDAV 凭据，不应公开分享。

## 当前限制

- AI 请求由浏览器直连用户配置的接口，API Key 只适合保存在个人或可信环境中。
- 画布以桌面端操作为主，移动端触控体验尚未完整适配。
- Docker 静态资源路径仍需要在更多生产环境中验证。
