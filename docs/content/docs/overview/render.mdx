# Deploy on Render

[Deploy to Render](https://render.com/deploy?repo=https://github.com/basketikun/infinite-canvas)

1. Select **Deploy to Render**.
2. Sign in and connect GitHub as prompted.
3. Confirm the deployment.

When deployment finishes, open the assigned domain. Billing, sleep behavior, and resource limits depend on the current Render configuration.

Canvas projects and assets remain in each visitor's browser by default. AI, prompt-source, and WebDAV requests originate in the browser. Verify static asset paths, cross-origin rules, and access to external endpoints in the target environment before relying on the deployment.
