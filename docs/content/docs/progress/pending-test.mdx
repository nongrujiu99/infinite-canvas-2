Only real OAuth2 tokens — `ya29.…` from `gcloud auth print-access-token`, or a service-account JWT starting with `eyJ` — use `Authorization: Bearer`; **every other key** (including `AQ.`, `AIza`, or any custom/truncated string) must go into the `?key=` query parameter with no `Authorization` header at all (and no `x-goog-api-key` header). A Vertex channel whose base URL still contains `projects/{project}/locations/{region}` must keep working after the URL is collapsed to `https://aiplatform.googleapis.com/v1`. "Test & save" must never come back with `Request had invalid authentication credentials` or `API keys are not supported by this API` for a non-OAuth key, and its error text should end with `（鉴权方式：?key= 查询参数；密钥：AQ.A…（N 字符））` so the auth mode and key fingerprint are visible.
- Vertex AI built-in model registry: once "Test & save" succeeds on a Vertex channel, the two image models (`gemini-3.1-flash-image`, `gemini-3-pro-image`) are always registered, and the text models are whatever the probe actually got HTTP 200 from — candidates `gemini-3.5-flash-lite`, `gemini-3.6-flash`, `gemini-3-flash-preview`, `gemini-3.1-flash`, `gemini-3.1-pro`, `gemini-3-pro`, `gemini-2.5-flash`, `gemini-2.5-flash-lite` are probed in parallel. Only verified ones may appear as text models, and the first verified one must become the default text model (canvas text node + prompt optimizer). Models that 404 in this project/region (e.g. `gemini-2.5-flash` under `asia-southeast1` → `Publisher model … was not found`) must not be registered. If none of the candidates answer, saving still succeeds but shows a warning that text chat may be unavailable. Leaving the model-name field empty must still save, and any custom name typed there is appended as an extra model.
- Vertex AI streaming text auth: text nodes (chat, prompt optimization) on a Vertex channel must authenticate correctly — the stream URL has to be `…:streamGenerateContent?key=…&alt=sse`, never `?key=…?alt=sse` (the latter corrupts the key and returns 401 「鉴权失败」). Verify that a text node streams a reply with the probe-verified text model, and that the image node on the same channel still works. A 404 must name the model in the message (e.g. `（模型：gemini-2.5-flash）`), distinguishing a wrong base URL from a model unavailable to this account.
- Vertex AI vision MIME normalization: attach an image to a text node on a Vertex channel and generate. The request must never carry `mimeType: application/octet-stream` — data URLs whose prefix is `application/octet-stream` (blob type lost during storage) must be sniffed from the file header and rewritten to `image/png` / `image/jpeg` / `image/webp` / `image/gif` / `image/bmp` / `image/avif` / `image/heic` / `image/svg+xml`, falling back to `image/png`. Verify with a PNG and a JPEG reference, and that generated-image references (stored without an explicit type) also pass.
