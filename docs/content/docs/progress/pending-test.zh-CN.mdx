# 待测试

- 电商全案工作台：使用 OpenAI Responses 与 Gemini 渠道分别验证分析模型被强制调用唯一 `submit_ecommerce_plan` 函数，函数参数来自规划 Zod Schema 生成的严格 JSON Schema；生成的 `rank` 与 `order` 应使用数值型 `minimum: 1`，不得出现布尔型 `exclusiveMinimum: true`，所有对象仍须保持 `additionalProperties: false` 且必填字段完整；OpenAI 电商分析应单独发送 `max_output_tokens: 16000`，不得影响 Gemini、普通文本或图片生成，达到边界时应归类为 `structured_output` 并保留可取得的 arguments。普通文本、无调用、错误函数名、多个调用、缺失或无效 arguments 以及渠道拒绝严格工具参数均应明确失败且不回退、不重试，自定义模型脚本应在请求前阻止；成功取得的 arguments 仍须通过本地 Zod 与业务校验。Schema 合法但业务校验失败的结果应保存为“待修正方案”，自动重算相邻差异并把非 Hero 任务主体模式固定为 `not_hero`；失败诊断中的合法原始响应可无请求载入为草案，全部业务错误须常驻显示并实时更新，错误归零前确认、版本创建和生成均应被 UI 与运行时阻止，刷新后草案与错误状态仍须保留。任一分析失败后应常驻显示失败分类、完整错误、模型、工作流、runId、时间、全部 Schema issue 和已有的函数 arguments，复制内容不得包含凭据，刷新后诊断仍存在，开始新分析或分析成功后清除；继续验证 Buyer Demand Map 6–10 项、标准商品 8–10 屏、复杂商品 10–14 屏、主图 5–8 张与六类角色、需求引用、相邻页面差异及错误启用集合均被拒绝；修改商品资料、语言、输出范围或素材后应中止或作废旧分析并取消方案确认，离开再返回不得重复发起同一项目分析；结构化方案分析超过 8 分钟应自动中止、进入“分析失败”并显示明确中文错误，且不得自动重试或影响图片生成超时。
- 电商全案执行：禁用中间任务后，主图和详情页 outputOrder、提示词编号、结果、ZIP 文件名和画布节点必须仍各自从 1 连续；结果卡必须直接按版本 outputOrder 排列；在两个项目同时生成时，全局活动请求不得超过 2，轮询调度不得让大版本持续占满槽位；同一项目只能有一个活动版本且版本号不得重复。生成中、暂停、ready、存在活动 runtime/controller 或同项目另有活动版本时，UI 与运行时均不得重做；修订提示词不得修改权威需求、卖点、可信度和精确图片文案，也不得把待确认事实或禁用声明作为正向内容；删除项目必须等待已暂停但尚未退出的请求。完成/无活动请求的部分失败版本重做后必须进入 generating 且不得重复发送；修改原渠道 baseUrl 后旧版本必须停止并提示恢复，API Key 不得进入版本、ZIP、策略文档或画布节点。
- 电商全案试跑：全套预检通过且项目没有活动版本时，可创建包含全部任务的不可变试跑版本；仅主图 outputOrder 1 与详情页 outputOrder 1 为 pending，其余任务为 canceled 且不得产生 attempt。两项成功后版本应暂停，失败时应部分失败且不自动重试；刷新须恢复完整快照、两项结果与其余 canceled 状态，明确继续后只补跑尚未成功的任务。确认弹窗须显示模型、两项任务、两种尺寸、2 次预计请求及其余任务不会请求，并防止重复确认创建版本。
- 电商任务素材路由：新版本应同时快照商品本体与包装素材，并为每个任务锁定 referenceAssetIds；普通任务仅引用全部商品本体图，包装任务额外引用全部包装图，模型能力按单任务最大引用数预检。继续、重试和重做必须沿用任务快照；素材 ID 或 Blob 缺失须明确失败；旧版本缺少任务素材 ID 时仅回退到自身快照中的商品本体素材。提示词与确认弹窗须准确说明各任务实际素材数量，且不得从包装图推断说明书、容量、赠品或额外配件。
- 电商全案本轮素材处理：用户已确认继续按“保温杯”验收并复用此前已生成的正确保温杯素材；带“4B ERASER”标识的旧素材及其 V1 试跑结果作废。应从浏览器本地素材库或旧项目取用正确保温杯素材，新建项目并重新分析、确认方案和创建试跑版本；旧 V1 不得继续生成，也不得作为商品一致性证据。
- 电商全案交付：切换旧版本时应展示该版本方案和 attempts；大图查看、人工复核标记、selected attempt、目标/请求/实际尺寸及任务统计应正确；ZIP 只包含当前版本选中 attempts；发送到新画布前任一资源缺失不得遗留空画布，成功发送需复用 storageKey 并生成策略文本、图片和分组节点。
- 电商全案界面与生命周期：验证确认前可编辑完整画面合同，修改权威需求/匹配记录会同步任务副本，相邻差异因素由结构化字段自动计算，非法修改无法确认；方案可编辑且没有活动版本时可新增、复制、跨类型复制和确认后删除任务，操作后主图与详情页应分别从 1 连续编号、使用新任务 ID、只提升一次 revision、取消确认并重算派生字段，版本快照状态下入口应禁用；项目 CRUD、分析中刷新/复制恢复、窄窗口和 125%–200% 缩放下三栏堆叠可达、纯键盘打开项目/重命名/操作图标按钮，输出范围、图片语言及所有任务控件均有明确可访问名称和清晰焦点；删除素材、版本或项目后，画布、素材库、复制项目及所有历史 attempts 仍引用的共享 Blob 不得误删。
- Agent 与插件移除：画布项目库及已有画布应可直接打开，不再出现 Agent 连接流程、扩展节点菜单、插件加载或相关本地存储项；内置文本、图片、视频、音频、生成配置、分组和处理节点的创建、编辑、连线、生成、撤销重做、ZIP 导入导出逻辑保持不变，自定义模型调用脚本继续正常工作。
- 生成配置模型选择：模型选择层应在节点内向上覆盖显示并跟随画布缩放，不改变节点尺寸或比例；搜索、最近使用、收藏、全部筛选、滚动和空状态应保持完整可用。
- 生成数量默认值：新建生成配置节点在文本、图片、视频和音频模式下的生成数量均应默认为 `1`，已有节点明确保存的数量不应被覆盖。
- 文档清理：README 和文档站只描述当前存在的页面、内置节点、生成、素材、存储与同步能力；商务合作、赞助、QQ群、贡献者榜单、Star History、远程展示图和相关导航入口不再出现，快速开始、画布手册及中英文导航仍可正常访问。
